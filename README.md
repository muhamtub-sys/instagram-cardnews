# 인스타그램 이슈 카드뉴스 자동 업로드 (무료, PC 없이)

하루 2번 그날의 주요 뉴스를 모아 AI가 정리해 인스타그램에 자동으로 올립니다. 같은 내용이 피드에 두 번 보이지 않게 회차마다 한 가지만 올립니다.

- **아침 07:00 — 릴스만**: 첫 화면 훅 한 줄 + 핵심 이슈 3가지(30~40초). 커버는 매번 같은 틀(남색 + 노란 날짜 배지)이라 프로필 격자가 정돈돼 보여요.
- **저녁 18:40 — 카드뉴스만**: 아침에 다룬 이슈는 빼고(`topics/날짜.json` 으로 기억) 5개. 이슈마다 '체크' 한 줄 + 마지막 장 체크리스트라 저장·공유용.
- 아침 릴스 제작이 실패하면 그 회차가 비지 않도록 같은 이슈로 카드뉴스를 대신 올립니다.
- 수동 실행(Actions → Run workflow)에서 `mode` 로 reel / cards 를 고를 수 있어요.

| 단계 | 쓰는 것 | 비용 |
|---|---|---|
| 자동 실행 | GitHub Actions (**공개 저장소**) | 무료·무제한 |
| 이슈 수집 | 구글 뉴스 RSS (한국 주요 뉴스) | 무료, 키 없음 |
| 정리·문구 | Google Gemini API 무료 등급 | 무료 |
| 카드 이미지 | Pillow + 본고딕(Noto Sans KR, 무료 폰트) | 무료 |
| 이미지 공개 주소 | 저장소 raw 주소 | 무료 |
| 게시 | Instagram Graph API (캐러셀) | 무료 |

디자인 미리보기: `preview/` 폴더 (예시 문구로 그린 카드)

## 설정 순서 (처음 한 번, 30분 정도)

### 1단계. 인스타 계정을 프로페셔널 계정으로
인스타 앱 → 프로필 → ☰ → 설정 → **계정 유형 및 도구** → **프로페셔널 계정으로 전환** → 크리에이터 선택.
(무료이고 언제든 되돌릴 수 있어요. 계정은 공개 상태여야 해요.)

### 2단계. Meta 앱 만들고 인스타 토큰 받기
> **2026-11 기준 바뀐 화면**: 새 앱은 "API setup with Unified login"만 쓸 수 있어요. 비즈니스 포트폴리오(무료)를 만들어 연결 → **새로운 구성 만들기** → 시스템 사용자 액세스 토큰, 자산 = 인스타 계정, 권한 `instagram_basic`·`instagram_content_publish` → 토큰(`EAA…`, 만료 없음) 복사.
> 이 경우 Variables 에 `IG_API_HOST` = `graph.facebook.com` 을 넣고, `IG_USER_ID` 는 비워둔 채 한 번 실행하면 로그에 인스타 계정 ID 가 나와요 (`python autopost.py --check`). 아래 1~6번은 예전 화면 기준이에요.

1. https://developers.facebook.com 에 페이스북 계정으로 로그인 → 처음이면 개발자 등록(무료).
2. **내 앱 → 앱 만들기** → 사용 사례에서 **"Instagram에서 메시지 및 콘텐츠 관리"**(Instagram API) 선택 → 앱 이름 아무거나 → 만들기.
3. 왼쪽 메뉴 **Instagram → API 설정(Instagram 로그인 사용)** 화면으로 이동.
4. **"액세스 토큰 생성"** 칸에서 **계정 추가** → 카드뉴스 올릴 인스타 계정으로 로그인 → 권한 허용.
   - 앱이 개발 모드여도 본인 계정이면 됩니다. 앱 검수 필요 없어요.
   - 계정 추가가 막히면: **앱 역할 → 역할 → Instagram 테스터 추가**로 내 인스타 아이디를 넣고, 인스타 앱(또는 웹)의 **설정 → 웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대**에서 수락한 뒤 다시 시도.
5. **토큰 생성** 버튼 → 나온 토큰을 복사 (이게 60일짜리 장기 토큰입니다).
6. 같은 화면 계정 옆에 있는 숫자(**Instagram 사용자 ID**, 보통 17841…)도 복사.

### 3단계. Gemini 키
https://aistudio.google.com/apikey → **API 키 만들기** → 복사. (쓰레드에서 쓰는 키를 그대로 써도 돼요.)

### 4단계. GitHub 저장소와 비밀값
1. GitHub에서 **Public** 저장소 만들기 (예: `instagram-cardnews`). 공개 저장소여야 Actions가 무제한 무료이고, 인스타가 카드 이미지를 가져갈 수 있어요. 키는 아래 Secrets 에 넣어서 공개되지 않아요.
2. 이 폴더의 파일을 저장소 루트에 올립니다. (저장소 이름을 알려주시면 Claude가 올려드려요.)
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 으로 3개 등록:
   - `IG_USER_ID` = 2단계 6번 숫자
   - `IG_ACCESS_TOKEN` = 2단계 5번 토큰
   - `GEMINI_API_KEY` = 3단계 키
4. 같은 화면 **Variables** 탭에서 (선택):
   - `BRAND` = 카드 왼쪽 위 이름 (기본 "이슈 한 장")
   - `HANDLE` = 내 인스타 아이디, 기본 `@issue_onecard` (실제 아이디가 다르면 꼭 바꾸기) (표지·마지막 장에 표시)
   - `ISSUE_COUNT` = 한 번에 다룰 이슈 수 (기본 5, 최대 8)

### 5단계. 첫 실행
저장소 **Actions → Instagram card news → Run workflow**. 2~3분 뒤 인스타에 올라오면 끝. 이후엔 매일 2번 자동으로 돌아갑니다.
- 실패하면 `posts.csv` 의 error 칸에 이유가 남아요. 그 줄 status 를 `skip` 으로 두면 다시 시도하지 않아요.
- 토큰만 빼두면(`IG_ACCESS_TOKEN` 미등록) 카드만 만들어 `images/` 에 쌓이니, 먼저 품질을 보고 싶을 때 써도 좋아요.

## 아침 릴스

아침 회차는 **주제 영상 릴스**(30~40초)만 올립니다.

- 이슈마다 Gemini 가 쓴 대본을 AI 음성(edge-tts, 무료)이 읽고, 그 주제에 맞는 무료 스톡 영상(Pixabay) 위에 제목·자막이 나옵니다.
- 필요한 것: Pixabay 무료 키 → Secrets 에 `PIXABAY_API_KEY` (https://pixabay.com/api/docs/ 로그인하면 key 가 보임). Pexels 키(`PEXELS_API_KEY`)도 지원.
- 키가 없거나 영상 제작이 실패하면 그 회차는 같은 이슈로 카드뉴스를 대신 올립니다.
- 주제에 맞는 영상을 못 찾은 장면은 해당 카드 이미지가 배경으로 들어갑니다.
- 실존 인물·실제 뉴스 화면은 쓰지 않습니다(분위기 영상만).
- 배경음: 저장소에 `music/` 폴더를 만들고 저작권 무료 음원을 넣으면 그중 하나를 씀. 없으면 직접 합성한 잔잔한 음.
- 인스타 인기 음원은 API로 붙일 수 없습니다.
- Variables 로 조절: `REELS=off`(아침에도 카드뉴스), `REEL_ISSUE_COUNT`(아침 이슈 수, 기본 3), `ISSUE_COUNT`(저녁 이슈 수, 기본 5), `REEL_STYLE=cards`(카드 슬라이드 영상), `REEL_VOICE=ko-KR-InJoonNeural`(남성 목소리)
- 영상 파일은 저장소가 커지지 않도록 `reels` 브랜치에 최신 것만 보관합니다.

## 알아둘 점
- **토큰은 60일마다 갱신**해야 해요. 2단계 4~5번을 다시 해서 `IG_ACCESS_TOKEN` 값만 바꾸면 됩니다.
- 시간 바꾸기: `.github/workflows/cardnews.yml` 의 `cron` (UTC 기준, 한국시간 −9시간). GitHub 예약 실행은 10~30분 늦을 수 있어요.
- 뉴스 출처 바꾸기: Variables 에 `NEWS_FEEDS` (RSS 주소, 쉼표로 여러 개). 예: 경제만 → 구글 뉴스 경제 섹션 RSS.
- AI는 뉴스 제목과 관련 기사 제목만 보고 요약하고, 자료에 없는 숫자·발언은 쓰지 않도록 지시했어요. 그래도 틀릴 수 있으니 처음 며칠은 올라간 글을 확인해 주세요.
- 기사 사진은 쓰지 않고 글자 카드만 만들어요 (저작권 문제 피하기).
- 계정당 24시간 API 게시 한도가 있어요 (하루 2번은 문제 없음). `python autopost.py --check` 로 확인.
